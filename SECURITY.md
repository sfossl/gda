# Security Policy

## Supported Versions

Security patches and updates are provided exclusively for the latest tagged release.

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues, pull requests or discussions.

To report a vulnerability:
1. Open an advisory report through [GitHub Private Vulnerability Reporting](https://github.com/sfossl/gda/security/advisories/new).
2. Include reproduction steps, affected components and potential impact.

Reports will be acknowledged within 48 hours. A fix will be developed and released before details are publicly disclosed.
